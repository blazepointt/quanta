# Quanta

Веб-клиент для работы с искусственным интеллектом через API Google Gemini. Приложение работает напрямую в браузере, поддерживает сохранение контекста, выбор моделей и тонкую настройку параметров генерации.

## Возможности

- Прямое подключение к OpenRouter (ключ хранится локально в браузере)
- Выбор актуальных моделей (Opus 4.8, Nemotron 3 ultra и др.)
- Настройка системных инструкций (System Instructions), температуры и лимитов токенов
- Поддержка форматирования Markdown и подсветки синтаксиса кода
- Локальное сохранение истории диалогов (LocalStorage / IndexedDB)
- Адаптивный интерфейс для десктопа и мобильных устройств
- Экспорт и очистка истории переписки

## Стек технологий

- HTML5, CSS3, Vanilla JavaScript
- Google Gemini API
- Библиотеки для рендеринга Markdown и подсветки кода

Безопасность данных

API-ключ и история сообщений сохраняются исключительно на клиенте (в хранилище вашего браузера) и передаются только на официальные эндпоинты Google API. Никакие сторонние серверы для проксирования запросов не используются.
