    2. 
                        
  2. Нажмите Create Key, придумайте любое название и скопируйте ключ — он начинается с sk-or-.
    3. 
                        
  3. Вставьте ключ в поле ниже — он сохранится сам. Готово: выберите модель в списке.

Быстрые пресеты

                    

                        
                        
                        
                    


                    

                        
                        

                            
                            
                        

                        

                        
Ключ хранится только в этом браузере и не попадает в резервные копии.

                    


                    

                        
                        
                        
По умолчанию: https://openrouter.ai/api/v1/chat/completions

                    


                    

                        
                        
                        
Нужна для Groq, Ollama и других провайдеров. Для OpenRouter модель выбирается в списке над полем ввода.

                            Как установить
                            
    
                                
  1. Скачайте файл Quanta-AI.apk. Если Chrome предупредит о типе файла, нажмите «Всё равно скачать».
    2. 
                                
  2. Откройте файл из уведомления или папки «Загрузки» и разрешите установку из этого браузера, если телефон спросит.
    3. 
                                
  3. Нажмите «Установить». Если появится окно Play Защиты, нажмите «Подробнее» → «Всё равно установить» — приложение новое, поэтому телефон его ещё не знает.
    4. 
                                
  4. Откройте Quanta AI и войдите через Google — чаты подтянутся сами.
    5. 
                            

                        

                        

                            На iPhone и iPad приложение ставится прямо из Safari: нажмите «Поделиться» (квадрат со стрелкой) → «На экран „Домой“» → «Добавить».
