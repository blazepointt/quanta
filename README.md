# Quanta AI

Чат с искусственным интеллектом прямо в браузере: ответы с потоковым выводом, поиск в интернете, генерация картинок и презентаций, работа с файлами и голосом. Вход через Google синхронизирует чаты, память и персонализацию между устройствами.

Сайт: https://quanta-app.pages.dev/

## Возможности

- **Чат с ИИ**: бесплатные модели без ключа или свой ключ OpenRouter / другого OpenAI‑совместимого провайдера (Groq, Ollama и т. п.).
- **Режимы**: поиск в интернете с источниками, генерация изображений, презентации (.pptx), анализ сайтов, файлов, архивов ZIP и фото.
- **Под каждым ответом**: «Повторить», «Копировать», «Озвучить», «Скачать .md», скорость генерации.
- **История**: поиск по чатам, удаление с отменой, синхронизация через аккаунт Google.

### Настройки (кнопка ⚙ или `Ctrl + ,`)

| Вкладка | Что внутри |
|---|---|
| **Персонализация** | Имя, род занятий, «о себе», стиль и тон ответов, язык, свои инструкции, предпросмотр того, что получит ИИ |
| **Память** | Список фактов о вас: добавить, изменить, удалить, найти, экспортировать, отменить удаление; автопамять; статус синхронизации |
| **Чат** | Размер шрифта, ширина чата, клавиша отправки, автопрокрутка, глубина контекста, язык голосового ввода, уведомления, горячие клавиши |
| **API** | Ключ и провайдер (готовые пресеты), проверка ключа, проверка соединения, температура |
| **Данные** | Статистика, экспорт чата в Markdown, резервная копия и восстановление (JSON), очистка истории и памяти, сброс настроек |

### Память

- ИИ сам запоминает устойчивые факты из разговора (имя, город, интересы, предпочтения) и показывает под сообщением «Запомнил: …» с кнопкой «Отменить».
- Команды в чате: «Запомни, что …», «Забудь, что …», «Забудь всё обо мне».
- Пароли, ключи API и номера карт в память не сохраняются. Команды «запомнить» из файлов и веб‑страниц игнорируются (защита от подмены).
- Автопамять и память целиком можно выключить в настройках.

### Горячие клавиши

`Enter` — отправить, `Shift + Enter` — новая строка, `Ctrl + K` — новый чат, `Ctrl + ,` — настройки, `/` — перейти к полю ввода, `Esc` — закрыть окно или остановить генерацию.

## Где хранятся данные

- **Без входа** — только в этом браузере (localStorage).
- **С входом через Google** — дополнительно в Firebase Firestore вашего проекта:
  - `users/{uid}/chats/{chatId}` и `users/{uid}/chats/{chatId}/messages/{id}` — чаты;
  - `users/{uid}/settings/profile` — персонализация и память.
- **API‑ключ** хранится только в браузере и не попадает ни в облако, ни в резервную копию.

## Публикация (Cloudflare Pages)

Сайт статический — сборка не нужна.

**Если Pages подключён к GitHub:** замените в репозитории файлы `index.html`, `app.js`, `styles.css`, `README.md` (на GitHub: *Add file → Upload files*, перетащить файлы, *Commit changes*). Cloudflare опубликует новую версию сам через 1–2 минуты.

**Если сайт загружался вручную:** Cloudflare → *Workers & Pages* → проект → *Create deployment* → загрузить папку с файлами.

После публикации обновите страницу с очисткой кэша: `Ctrl + F5`.

## Настройка Firebase (для входа и синхронизации)

1. *Authentication → Sign-in method*: включён **Google**.
2. *Authentication → Settings → Authorized domains*: есть ваш домен (например, `quanta-app.pages.dev`).
3. *Firestore Database → Rules* — разрешите каждому пользователю доступ только к своим данным (нужно для синхронизации памяти и персонализации):

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```

Если правила разрешают только `chats`, чаты будут синхронизироваться, а память и персонализация — храниться только на устройстве (в настройках появится подсказка).
