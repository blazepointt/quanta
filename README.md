# Quanta

**Quanta** — универсальная AI-платформа, которая работает прямо в браузере: без бэкенда, без серверов, без API-ключей. Один HTML-файл — а внутри полноценный AI-ассистент, который умеет думать, писать, анализировать, рисовать и исследовать.

Всё, что обычно требует отдельных сервисов и подписок, здесь собрано в одном месте:

- 💬 **Чат с реальной нейросетью** — свободный диалог на базе GPT-4o / GPT-4o-mini
- 📄 **Анализ документов** — загрузи PDF, DOCX или TXT — Quanta прочитает и разложит по полочкам
- 📊 **Анализ таблиц** — CSV/Excel превращаются в статистику, кластеры и графики за секунды
- 🎨 **Генерация изображений** — опиши картинку словами, получи готовое изображение
- 📽 **Генерация презентаций** — тема на входе, готовый скачиваемый `.pptx` на выходе
- 🔍 **Deep Research** — Quanta сама раскладывает сложную тему на подвопросы и последовательно в них разбирается
- 🌐 **Анализ сайтов** — вставь ссылку, получи структурированную выжимку содержимого
- 🧑‍💻 **Помощь в коде** и 🌍 **умный перевод** — в том же чате, под капотом
- 🎙 **Голосовой ввод** — говори, а не печатай

Никакой регистрации, никакого сервера — просто открой сайт и начни пользоваться.

## Технологии

Чистый HTML/CSS/JS без сборки — все возможности подключены через CDN:
[Puter.js](https://js.puter.com/v2/) (реальные модели + генерация изображений) · [pdf.js](https://mozilla.github.io/pdf.js/) · [mammoth.js](https://github.com/mwilliamson/mammoth.js) · [PapaParse](https://www.papaparse.com/) · [SheetJS](https://sheetjs.com/) · [Chart.js](https://www.chartjs.org/) · [PptxGenJS](https://gitbrent.github.io/PptxGenJS/)

## Запуск

Сайт нужно открывать через веб-сервер (например GitHub Pages), а не двойным кликом по файлу — иначе Puter.js заблокирует работу по соображениям безопасности (`file://` не поддерживается).

1. Залей `quanta.html` в репозиторий (можно переименовать в `index.html`)
2. Включи **Settings → Pages** для ветки `main`
3. Через пару минут сайт будет доступен по `https://<логин>.github.io/<репозиторий>/`

### Частые вопросы
- **Открылось окно входа Puter** — нормально, бесплатный доступ к моделям устроен именно так; один раз войти или получить временный доступ автоматически.
- **Окно входа — белый экран, ответ не приходит** — обычно виноват блокировщик рекламы или запрет всплывающих окон/сторонних cookies.
- **Deep Research** отвечает на основе знаний модели, а не живого поиска в интернете.
- **Анализ сайтов** идёт через публичный CORS-прокси — может быть временно недоступен для некоторых сайтов.
