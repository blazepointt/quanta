# Quanta AI

Чат с искусственным интеллектом прямо в браузере: ответы с потоковым выводом, поиск в интернете, генерация картинок и презентаций, работа с файлами, голосовой разговор, ссылки на чаты, светлая и тёмная тема. Ставится как приложение на телефон и компьютер. Вход через Google синхронизирует чаты, память и персонализацию между устройствами.

Сайт: https://quanta-app.pages.dev/

## Возможности

- **Чат с ИИ**: работает сразу без ключа; с бесплатным ключом OpenRouter доступны модели посильнее. Можно подключить и другого OpenAI‑совместимого провайдера (Groq, Ollama и т. п.).
- **Режимы**: поиск в интернете с источниками, генерация изображений, презентации (.pptx), анализ сайтов, файлов, архивов ZIP и фото.
- **Под каждым ответом**: название модели, которая на самом деле ответила, «Повторить», «Копировать», «Озвучить», «Скачать .md», скорость генерации. Пока модель думает, видно «Размышляет…».
- **Код**: для вопросов про программирование включаются отдельные правила (полный рабочий код, без выдуманных функций) и более «точная» температура.
- **Голосовой разговор**: говорите с ИИ голосом, как в ChatGPT, — он отвечает вслух ([подробнее](#голосовой-разговор)).
- **Ссылки на чаты**: отправьте чат кому угодно — его можно прочитать и продолжить ([подробнее](#ссылки-на-чаты)).
- **Оформление**: тёмная, светлая или как в системе, 7 цветов акцента, 5 размеров текста ([подробнее](#оформление)).
- **Приложение**: значок на рабочем столе или главном экране, отдельное окно, запуск без интернета ([подробнее](#приложение)).
- **История**: поиск по чатам, удаление с отменой, синхронизация через аккаунт Google.

## Модели

В меню над полем ввода только настоящие названия — что выбрано, то и отвечает. Если модель занята, ответит запасная, и это будет написано.

| Группа | Модели |
|---|---|
| **Без ключа** | **GPT-OSS 20B** (открытая модель OpenAI, через бесплатный сервис Pollinations) и режим **Картинки** |
| **Бесплатно с ключом OpenRouter** | Nemotron 3 Ultra, Nemotron 3.5 Lightning (NVIDIA), Gemma 4 31B (Google, понимает фото), North Mini Code (Cohere, для кода), Автовыбор (любая свободная бесплатная) |
| **Платные — нужен баланс OpenRouter** | Kimi K3, Qwen3 Coder, GLM 5.3, DeepSeek V4 Flash |

**Как получить бесплатный ключ OpenRouter:**

1. Откройте [openrouter.ai/keys](https://openrouter.ai/keys) и войдите (можно через Google).
2. Нажмите **Create Key**, введите любое название и скопируйте ключ — он начинается с `sk-or-`.
3. В Quanta: **Настройки → API** → вставьте ключ в поле «API‑ключ». Он сохранится сам — выберите модель в меню.

Без ключа фото и скриншоты не распознаются (для этого нужна Gemma 4 31B с ключом). У бесплатных моделей есть дневной лимит запросов OpenRouter.

## Картинки

Включите режим **Картинки** в меню моделей (или кнопкой с картинкой у поля ввода). Над полем появится панель:

- **Формат**: Авто (по смыслу запроса: «обои на телефон» → вертикальный, «баннер» → широкий), 1:1, 16:9, 9:16, 4:3, 3:4, 3:2, 2:3, 21:9. Максимум — 1024 px по длинной стороне (ограничение бесплатного сервиса).
- **Стиль**: Фото, Кино, Аниме, Цифровой арт, 3D, Масло, Акварель, Пиксель‑арт, Карандаш, Комикс, Фэнтези, Киберпанк, Минимализм, Логотип.
- **Улучшать описание**: ИИ переводит запрос на английский и добавляет детали (свет, композиция, атмосфера). Если выключить — только перевод.
- **Ещё**: «Исключить» (что не должно быть на картинке) и «Сид» (одинаковый сид + то же описание = та же картинка).
- **×** — вернуться в обычный чат.

Под картинкой: «Скачать», «На весь экран», **«Ещё вариант»** (тот же промпт, другая картинка — работает и для картинок из истории), «Перегенерировать» и «Промпт для нейросети» (что именно ушло генератору, с кнопкой копирования). Картинки рисует бесплатный сервис Pollinations; без ключа у него лимит — примерно одна картинка в 45 секунд, приложение подождёт и повторит само.

## Голосовой разговор

Когда поле ввода пустое, кнопка «Отправить» превращается в кнопку с **волной**. Нажмите её и говорите:

1. Quanta слушает — после паузы вопрос уходит сам (подпись показывает, что распозналось).
2. ИИ думает и отвечает **вслух** — коротко, как в живом разговоре. Полный ответ (с кодом, таблицами и формулами) остаётся в чате на экране.
3. Когда ответ прозвучал, Quanta снова слушает — можно сразу задавать следующий вопрос.

Управление: **круг** — перебить ответ или остановить «Думаю…»; **микрофон** — пауза; **×** или `Esc` — завершить. Можно и голосом: «стоп», «хватит», «пока».

Голос и скорость речи — *Настройки → Чат → Голос* (кнопка «Прослушать»), там же язык распознавания. Эти же голос и скорость использует кнопка «Озвучить» под ответами.

- Работает в **Chrome, Edge, Яндекс Браузере, Safari** и на телефоне (Android — Chrome). В **Firefox и Zen** распознавания речи нет — откройте Quanta на телефоне или в Chrome.
- Речь распознаёт сервис браузера (в Chrome — серверы Google), поэтому нужен интернет. При первом запуске браузер спросит разрешение на микрофон — нажмите «Разрешить».

## Ссылки на чаты

Кнопка **«Поделиться»** (квадрат со стрелкой) в шапке чата → **«Копировать»** → отправьте ссылку кому угодно.

- **С входом через Google** — короткая ссылка `…/?s=…`. Повторное нажатие даёт ту же ссылку с новыми сообщениями; кнопка «Удалить ссылку» закрывает к ней доступ. Нужны правила Firestore из раздела [Настройка Firebase](#настройка-firebase-для-входа-и-синхронизации); пока они старые, Quanta сделает ссылку второго вида.
- **Без входа** — чат упаковывается прямо в ссылку (`…/#c=…`), на сервере ничего не хранится. В очень длинных чатах в такую ссылку попадают последние сообщения.
- Кто открыл ссылку, видит чат с плашкой «Общий чат» и может продолжить его у себя: просто написать сообщение или нажать «Сохранить себе». Ваша память, настройки и другие чаты по ссылке не передаются, а из сохранённого чужого чата Quanta ничего не запоминает о пользователе.

## Оформление

*Настройки → Оформление*:

- **Тема**: тёмная, светлая или «Как в системе» (переключается вместе с Windows, Android, iOS).
- **Цвет акцента**: монохром, синий, фиолетовый, зелёный, оранжевый, розовый, бирюзовый — кнопка «Отправить», переключатели, ваши сообщения и ссылки.
- **Размер текста**: от «Мелкий» до «Максимальный» — меняется и текст сообщений, и поле ввода. Там же ширина чата.

Оформление хранится на устройстве: на телефоне и компьютере можно выбрать разное.

## Приложение

Quanta ставится как приложение: значок на рабочем столе или главном экране, отдельное окно без адресной строки, быстрый запуск. Без интернета приложение всё равно откроется — история и настройки на месте (для ответов ИИ сеть нужна).

- **Android (Chrome)**: меню **⋮** → **«Установить приложение»** (или «Добавить на главный экран»).
- **Компьютер (Chrome, Edge, Яндекс Браузер)**: значок установки в правой части адресной строки или кнопка «Установить приложение» в боковом меню Quanta.
- **iPhone, iPad**: Safari → **Поделиться** → **На экран «Домой»**.
- **Firefox и Zen** на компьютере сайты как приложения не устанавливают — используйте Chrome или Edge, либо телефон.

Подсказка для вашего браузера: *Настройки → Оформление → Приложение*. Долгое нажатие на значок (или правый клик) открывает ярлыки: «Новый чат», «Голосовой разговор», «Нарисовать картинку». Обновления приходят сами: новая версия загружается при следующем запуске с интернетом.

| Вкладка | Что внутри |

| **Память** | Список фактов о вас: добавить, изменить, удалить, найти, экспортировать, отменить удаление; автопамять; статус синхронизации |
| **Оформление** | Тема (тёмная, светлая, как в системе), цвет акцента, размер текста, ширина чата, установка приложения |
| **Чат** | Клавиша отправки, автопрокрутка, скорость генерации, кнопки под ответами, сигнал о готовности; голос — язык распознавания, голос и скорость озвучки, «Прослушать»; горячие клавиши |
| **API** | Инструкция, как получить бесплатный ключ, ключ и провайдер (готовые пресеты), проверка ключа и соединения, температура |
| **Данные** | Статистика, экспорт чата в Markdown, резервная копия и восстановление (JSON), очистка истории и памяти, сброс настроек |

### Память

- ИИ сам запоминает устойчивые факты из разговора (имя, город, интересы, предпочтения) и показывает под сообщением «Запомнил: …» с кнопкой «Отменить».
- Команды в чате: «Запомни, что …», «Забудь, что …», «Забудь всё обо мне».
- Пароли, ключи API и номера карт в память не сохраняются. Команды «запомнить» из файлов и веб‑страниц игнорируются (защита от подмены).
- Автопамять и память целиком можно выключить в настройках.

### Горячие клавиши

`Enter` — отправить, `Shift + Enter` — новая строка, `Ctrl + K` — новый чат, `Ctrl + ,` — настройки, `/` — перейти к полю ввода, `Esc` — закрыть окно, остановить генерацию или завершить голосовой разговор.

## Где хранятся данные

- **Без входа** — только в этом браузере (localStorage).
- **С входом через Google** — дополнительно в Firebase Firestore вашего проекта:
  - `users/{uid}/chats/{chatId}` и `users/{uid}/chats/{chatId}/messages/{id}` — чаты;
  - `users/{uid}/settings/profile` — персонализация и память;
  - `shares/{id}` — только те чаты, которыми вы поделились по ссылке (до удаления ссылки).
- **API‑ключ** хранится только в браузере и не попадает ни в облако, ни в резервную копию, ни в ссылки на чаты.
- **Оформление** (тема, цвет, размер текста) — в браузере этого устройства.

## Публикация (Cloudflare Pages)

Сайт статический — сборка не нужна.

**Если Pages подключён к GitHub:** загрузите в репозиторий все файлы проекта — `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest`, `README.md` и папку `assets` (на GitHub: *Add file → Upload files*, перетащить файлы и папку, *Commit changes*). Cloudflare опубликует новую версию сам через 1–2 минуты.

`sw.js` и `manifest.webmanifest` должны лежать рядом с `index.html` (в корне сайта) — без них не будет установки как приложения и запуска без интернета.

**Если сайт загружался вручную:** Cloudflare → *Workers & Pages* → проект → *Create deployment* → загрузить папку с файлами.

После публикации обновите страницу с очисткой кэша: `Ctrl + F5`.

## Настройка Firebase (для входа и синхронизации)

1. *Authentication → Sign-in method*: включён **Google**.
2. *Authentication → Settings → Authorized domains*: есть ваш домен (например, `quanta-app.pages.dev`).
3. *Firestore Database → Rules* — замените текст правил на этот и нажмите **Publish**. Первый блок даёт каждому пользователю доступ только к своим данным (чаты, память, персонализация), второй — нужен для коротких ссылок на чаты: открыть общий чат может любой, у кого есть ссылка, а создать, изменить или удалить — только автор. Перечислить чужие ссылки нельзя.

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
    match /shares/{shareId} {
      allow get: if true;
      allow list: if false;
      allow create: if request.auth != null
        && request.resource.data.ownerUid == request.auth.uid
        && request.resource.data.messages is list
        && request.resource.data.messages.size() <= 1000;
      allow update: if request.auth != null
        && resource.data.ownerUid == request.auth.uid
        && request.resource.data.ownerUid == request.auth.uid
        && request.resource.data.messages is list
        && request.resource.data.messages.size() <= 1000;
      allow delete: if request.auth != null && resource.data.ownerUid == request.auth.uid;
    }
  }
}
```

Если правила разрешают только `chats`, чаты будут синхронизироваться, а память и персонализация — храниться только на устройстве (в настройках появится подсказка). Без блока `shares` ссылки на чаты всё равно работают — чат хранится прямо в ссылке.
